The 15 movement sounds drop an audio file on a slot (or several files on this box, named like 05-jump.wav)

Settings

Only one movement sound plays at a time. A new movement cuts the old sound. Quick moves (spin, jump, hop, kick, lunge, stomp, toe tap) play once; lasting ones (still, walk, run, skip, dancer's pose, tilt, sky, shuffle) loop while you keep doing them. Change that with each slot's loop box.

Adding your sounds

Drag and drop an audio file (WAV, MP3, OGG, M4A) onto a slot, or click Choose. Dropped sounds are saved in this browser and come back next time.

Or a folder: put files in sampler/sounds/ named by number and movement, e.g. 01-still.mp3, 05-jump.wav, 12-toetap.ogg. They load when the page opens. A dropped sound wins over the folder.

Test on a slot pretends that movement happened, so you can try sounds without the shoes. Slots marked both shoes are only detected with both shoes connected.
