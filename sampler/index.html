Running plays at the Running level (100% = as loud as this app goes, so turn the laptop volume up too). Standing still for 2 seconds pauses the sound. It picks up where it left off when you move again.

How to play

Walk: normal volume. Run: max volume. Stand still for 2 seconds: the sound pauses. Spin 360 on one foot or both: next sound. Both feet spinning together count as one spin.

Each shoe decides what it's doing by itself. The app plays the loudest one: if either shoe runs, it's loud. It only pauses when both shoes are still.

Keyboard for testing without shoes: W walk, R run, X still, S spin, 1-4 pick a sound.
