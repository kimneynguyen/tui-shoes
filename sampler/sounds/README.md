# Movement sounds

Put one audio file per movement in this folder. The app loads them when the page opens
(it has to be opened from `python3 -m http.server`, not by double-clicking the file).
Any of `.mp3`, `.wav`, `.ogg`, `.m4a` works. Leave a movement out to keep its slot empty.

| File name | Movement |
|---|---|
| `01-still` | Standing still |
| `02-walk` | Walking |
| `03-run` | Running |
| `04-spin` | Spin |
| `05-jump` | Jump with both feet |
| `06-hop` | Hop on one foot |
| `07-skip` | Skipping |
| `08-kick` | Karate kick |
| `09-lunge` | Giant step / lunge |
| `10-dancer` | Dancer's pose |
| `11-stomp` | Stomp |
| `12-toetap` | Toe tap |
| `13-tilt` | Foot tilt |
| `14-sky` | Both feet to the sky |
| `15-shuffle` | Shuffle / slide |

Example: `05-jump.wav`. You can also drag files onto the slots in the app instead.
